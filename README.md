# Реестр Pulse: кому звонить

Внутренний инструмент Pulse Digital для холодных звонков. Одна статичная страница (`index.html`), без сборки.

## Файлы
- `index.html` — сама страница.
- `middleware.js` — вход по логину и паролю. Без него реестр с ФИО и телефонами будет открыт всем.
- `vercel.json` — запрет индексации и кэша.
- `robots.txt` — поисковикам вход закрыт.

## Деплой на Vercel
1. Vercel → Add New → Project → выбрать этот репозиторий. Framework Preset: **Other**. Build Command и Output Directory оставить пустыми.
2. До первого деплоя: Settings → Environment Variables → добавить `BASIC_USER` и `BASIC_PASS` (Production + Preview).
3. Deploy. При открытии ссылки браузер спросит логин и пароль.

Если переменные поменяли после деплоя, нужен Redeploy.

## Ограничения
Статусы звонков и заметки хранятся в браузере каждого человека, общей базы нет. Чтобы передать работу, используй кнопку «Скачать в Excel».
